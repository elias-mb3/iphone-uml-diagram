# 📱 iPhone Simulator - POO Java Project

Projeto desenvolvido durante o **Desafio de Programação Orientada a Objetos (POO)** da [DIO](https://www.dio.me/), com o objetivo de simular o funcionamento básico de um iPhone com três principais funcionalidades:

- 🎵 Reprodutor Musical
- ☎️ Aparelho Telefônico
- 🌐 Navegador de Internet

## 🔧 Tecnologias Utilizadas

- Java 17+
- Programação Orientada a Objetos
- Interfaces e Classes
- Estrutura de Projeto Java com Pacotes

## 🧠 Conceitos Trabalhados

- Interfaces e implementação
- Encapsulamento
- Modularização
- Organização de pacotes (packages)
- Simulação de funcionalidades reais

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/iphone-poo.git
```

2. Navegue até o diretório:

```bash
cd iphone-poo
```

3. Compile e execute o projeto:

```bash
cd src/main/java
javac iphone/app/Main.java
java iphone.app.Main
```
